# 05 — Database Schema

PostgreSQL 16+ with `pgvector`. IDs are **UUIDv7** generated by the application (time-ordered, index-friendly, and clients can mint them offline). Verify the pgvector version you deploy, as index features differ between releases.

## 1. Extensions and types
```sql
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE EXTENSION IF NOT EXISTS citext;

CREATE TYPE document_kind AS ENUM ('note','url','pdf','image','audio');
CREATE TYPE ingestion_status AS ENUM ('queued','extracting','chunking','embedding','ready','failed');
CREATE TYPE message_role AS ENUM ('user','assistant','system');
```

## 2. Identity
```sql
CREATE TABLE users (
  id            uuid PRIMARY KEY,
  email         citext NOT NULL UNIQUE,
  password_hash text   NOT NULL,
  display_name  text,
  created_at    timestamptz NOT NULL DEFAULT now(),
  updated_at    timestamptz NOT NULL DEFAULT now(),
  deleted_at    timestamptz
);

CREATE TABLE sessions (
  id          uuid PRIMARY KEY,
  user_id     uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  family_id   uuid NOT NULL,
  token_hash  bytea NOT NULL UNIQUE,
  device_name text,
  created_at  timestamptz NOT NULL DEFAULT now(),
  expires_at  timestamptz NOT NULL,
  rotated_at  timestamptz,
  revoked_at  timestamptz,
  replaced_by uuid
);
CREATE INDEX ix_sessions_user ON sessions(user_id);
CREATE INDEX ix_sessions_family ON sessions(family_id);
```

## 3. Library
```sql
CREATE TABLE collections (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name text NOT NULL,
  color text,
  version int NOT NULL DEFAULT 1,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz,
  UNIQUE (user_id, name)
);

CREATE TABLE documents (
  id            uuid PRIMARY KEY,
  user_id       uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  collection_id uuid REFERENCES collections(id) ON DELETE SET NULL,
  kind          document_kind NOT NULL,
  title         text NOT NULL,
  body          text,                   -- notes only
  source_url    text,
  storage_key   text,                   -- original file in object storage
  mime_type     text,
  size_bytes    bigint,
  content_hash  bytea,                  -- sha256 for dedupe
  language      text,
  page_count    int,
  chunk_count   int NOT NULL DEFAULT 0,
  tags          text[] NOT NULL DEFAULT '{}',
  status        ingestion_status NOT NULL DEFAULT 'queued',
  error_code    text,
  error_detail  text,
  version       int NOT NULL DEFAULT 1,
  created_at    timestamptz NOT NULL DEFAULT now(),
  updated_at    timestamptz NOT NULL DEFAULT now(),
  deleted_at    timestamptz
);
CREATE INDEX ix_documents_user_created ON documents(user_id, created_at DESC, id DESC) WHERE deleted_at IS NULL;
CREATE INDEX ix_documents_user_collection ON documents(user_id, collection_id) WHERE deleted_at IS NULL;
CREATE INDEX ix_documents_title_trgm ON documents USING gin (title gin_trgm_ops);
CREATE UNIQUE INDEX uq_documents_user_hash ON documents(user_id, content_hash)
  WHERE content_hash IS NOT NULL AND deleted_at IS NULL;
```

## 4. Chunks, full-text and vectors
```sql
CREATE TABLE chunks (
  id           uuid PRIMARY KEY,
  user_id      uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  document_id  uuid NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
  ordinal      int  NOT NULL,
  text         text NOT NULL,
  token_count  int  NOT NULL,
  heading_path text[] NOT NULL DEFAULT '{}',
  page_start   int,
  page_end     int,
  char_start   int,
  char_end     int,
  tsv          tsvector GENERATED ALWAYS AS (to_tsvector('english', text)) STORED,
  created_at   timestamptz NOT NULL DEFAULT now(),
  UNIQUE (document_id, ordinal)
);
CREATE INDEX ix_chunks_user_doc ON chunks(user_id, document_id);
CREATE INDEX ix_chunks_tsv ON chunks USING gin (tsv);

CREATE TABLE embedding_models (
  key        text PRIMARY KEY,           -- e.g. bge_small_en_v15
  hf_name    text NOT NULL,
  dim        int  NOT NULL,
  table_name text NOT NULL,
  is_active  boolean NOT NULL DEFAULT false,
  created_at timestamptz NOT NULL DEFAULT now()
);

-- One table per embedding model so each has its own fixed dimension and index.
CREATE TABLE chunk_embeddings_bge_small_en_v15 (
  chunk_id  uuid PRIMARY KEY REFERENCES chunks(id) ON DELETE CASCADE,
  user_id   uuid NOT NULL,                -- denormalised for filter-first search
  embedding vector(384) NOT NULL
);
CREATE INDEX ix_emb_bge_small_user ON chunk_embeddings_bge_small_en_v15(user_id);
```
Notes:
- Postgres FTS (`ts_rank_cd`) is **not** BM25. Treat it as the pragmatic lexical retriever and compare it against a true BM25 implementation in the eval (doc 12).
- Use the `english` config for the English-first MVP. For multilingual content add a `simple`-config column or move lexical search to a BM25 library later.

### Vector search strategy
1. **Start exact, per user.** `SELECT chunk_id, embedding <=> :q AS dist FROM ... WHERE user_id = :uid ORDER BY dist LIMIT 40` uses the `user_id` index and computes exact distances. For tens of thousands of vectors per user this is fast and has perfect recall.
2. **Add HNSW when a benchmark demands it**:
```sql
CREATE INDEX ix_emb_bge_small_hnsw
  ON chunk_embeddings_bge_small_en_v15 USING hnsw (embedding vector_cosine_ops)
  WITH (m = 16, ef_construction = 64);
-- query time
SET LOCAL hnsw.ef_search = 100;
```
3. **Filtered ANN caveat**: an HNSW index scans the global graph and then applies `WHERE user_id = ...`, which can return fewer rows than requested. Use iterative index scans if your pgvector version supports them, partition by user hash, or keep exact search for small tenants. Record the benchmark that justifies the choice in an ADR.

## 5. Chat
```sql
CREATE TABLE conversations (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  collection_id uuid REFERENCES collections(id) ON DELETE SET NULL,
  title text,
  version int NOT NULL DEFAULT 1,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  deleted_at timestamptz
);
CREATE INDEX ix_conversations_user_updated ON conversations(user_id, updated_at DESC);

CREATE TABLE messages (
  id uuid PRIMARY KEY,
  conversation_id uuid NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
  user_id uuid NOT NULL,
  role message_role NOT NULL,
  content text NOT NULL DEFAULT '',
  status text NOT NULL DEFAULT 'complete',     -- streaming | complete | failed | abstained
  pipeline_config jsonb,                       -- exact retrieval/generation config used
  timings_ms jsonb,                            -- rewrite, retrieve, rerank, ttft, total
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_messages_conv ON messages(conversation_id, created_at);

CREATE TABLE message_citations (
  message_id  uuid NOT NULL REFERENCES messages(id) ON DELETE CASCADE,
  marker      int  NOT NULL,                   -- [1], [2] ...
  chunk_id    uuid REFERENCES chunks(id) ON DELETE SET NULL,
  document_id uuid REFERENCES documents(id) ON DELETE SET NULL,
  doc_title   text NOT NULL,                   -- snapshot, survives deletion
  page_start  int,
  snippet     text NOT NULL,                   -- snapshot of cited passage
  score       real,
  PRIMARY KEY (message_id, marker)
);

CREATE TABLE feedback (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  message_id uuid NOT NULL REFERENCES messages(id) ON DELETE CASCADE,
  rating smallint NOT NULL CHECK (rating IN (-1, 1)),
  reason text,                                 -- wrong_source | hallucination | incomplete | other
  comment text,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

## 6. Jobs, usage, sync, idempotency
```sql
CREATE TABLE ingestion_jobs (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL,
  document_id uuid NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
  attempt int NOT NULL DEFAULT 1,
  stage text NOT NULL,
  started_at timestamptz NOT NULL DEFAULT now(),
  heartbeat_at timestamptz NOT NULL DEFAULT now(),
  finished_at timestamptz,
  error text,
  stats jsonb
);
CREATE INDEX ix_jobs_document ON ingestion_jobs(document_id);

CREATE TABLE llm_calls (
  id uuid PRIMARY KEY,
  user_id uuid NOT NULL,
  message_id uuid,
  purpose text NOT NULL,          -- rewrite | answer | judge | title
  model text NOT NULL,
  prompt_tokens int, completion_tokens int,
  latency_ms int, cost_usd numeric(10,6),
  trace_id text,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_llm_calls_user_created ON llm_calls(user_id, created_at DESC);

CREATE TABLE change_log (
  seq bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  user_id uuid NOT NULL,
  entity text NOT NULL,            -- document | collection | conversation | message
  entity_id uuid NOT NULL,
  op text NOT NULL,                -- upsert | delete
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_change_log_user_seq ON change_log(user_id, seq);

CREATE TABLE idempotency_keys (
  user_id uuid NOT NULL,
  key text NOT NULL,
  request_hash bytea NOT NULL,
  response_status int NOT NULL,
  response_body jsonb NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (user_id, key)
);
```
`change_log` is appended in the same transaction as the entity change (via service layer or trigger). A global `seq` is monotonic; per-user reads use the `(user_id, seq)` index.

## 7. Row Level Security (defence in depth)
```sql
ALTER TABLE documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY documents_owner ON documents
  USING (user_id = current_setting('app.user_id', true)::uuid);
-- repeat for every tenant-owned table; application role must not be a superuser or table owner
```
Test: with `app.user_id` set to user A, a raw `SELECT * FROM documents` returns zero of user B's rows.

## 8. Migration rules (expand and contract)
1. Add nullable column or new table (deploy).
2. Backfill in batches (job), dual-write if needed.
3. Switch reads.
4. Add constraint / drop old column in a later release.
Never edit applied migrations; never run destructive DDL in the same release that stops using the data. CI runs `alembic upgrade head` on an empty database and `alembic check` for drift.

## 9. Deletion and export
- User-visible deletes are **soft** (`deleted_at`) so sync can propagate tombstones; a purge job hard-deletes after 30 days, including chunks, embeddings and storage objects.
- **Account deletion**: revoke sessions, schedule purge of everything keyed by `user_id`, delete storage prefix `users/{id}/`.
- **Export**: async job producing a zip (JSON metadata + original files) available through a short-lived presigned URL.

## 10. Embedding model migration
1. Create new embeddings table and register in `embedding_models` (inactive).
2. Re-embed job fills it in the background.
3. Run eval comparing old and new.
4. Flip `is_active`; keep the old table one release for rollback; then drop.
