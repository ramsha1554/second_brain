# Phase 8 — Polish and Packaging (about 1 week)

## Goal
Make the work easy to evaluate in five minutes and deep enough for a two-hour deep dive.

## Tasks
**Repository**
- [ ] README per doc 19 with demo GIF/video, results table, diagrams, quickstart
- [ ] Architecture diagrams exported as images; docs index checked for broken links
- [ ] LICENSE, CONTRIBUTING (short), SECURITY.md (how to report), CODE_OF_CONDUCT optional
- [ ] Remove dead code and TODOs without issues; ensure issue tracker is tidy with a public roadmap
- [ ] Tag `v1.0`; GitHub Release with APK and changelog; pin repo and set topics

**Demo and content**
- [ ] 3-minute demo video (script in doc 19); short feature clips for README
- [ ] Screenshots light/dark, phone/tablet; store listing style images
- [ ] Technical blog post on the evaluation and ablations; short post on offline sync
- [ ] Optional: public, rate-limited demo instance with a sample account and sample data (document privacy)

**Resume and interview prep**
- [ ] Fill resume bullets with real numbers from reports
- [ ] Prepare a one-page "project brief" and a 10-minute architecture walkthrough
- [ ] Rehearse failure stories and trade-off answers (doc 19 talking points)

**Quality pass**
- [ ] Fresh clone test: follow README on a clean machine/VM
- [ ] Verify CI badges green, coverage and eval badges updated
- [ ] Check licences of all dependencies and datasets
- [ ] Final security scan and dependency update

## Exit criteria
- [ ] A reviewer can run the stack and app from the README in under 15 minutes
- [ ] Every claim in the README links to evidence (report, test, dashboard)
- [ ] Portfolio evidence checklist (doc 19) fully ticked
- [ ] Limitations and roadmap are honest and specific
